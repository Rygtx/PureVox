# PureVox 使用说明（Linux）

## 安装与启动

Linux 版音频采集/输出/虚拟麦克风全部使用系统原生 **PipeWire**。请先用发行版包管理器安装
**pipewire** 与 **libpipewire** 开发包（各发行版包名略有不同，如 AOSC 的
pipewire libpipewire-0.3-devel ，见 README），并保证 PipeWire 正在运行
（ systemctl --user status pipewire ）。

运行方式（任选其一）：

1. 安装包：按发布页下载 deb（Debian/Ubuntu 系）、rpm（Fedora 系）或 AppImage，
   安装后从桌面/应用菜单启动，或命令行执行 purevox ；
2. 源码运行： ./bootstrap_python312.sh 准备内嵌 Python 3.12 后，
    ./py312 run_tk.py 启动。

## 第 1 步：选择设备

1. **输入设备**：选择物理麦克风。Linux 按**声卡**枚举设备——
    一个声卡有多个**接口**（如板载声卡的数字麦 Mic1 / 模拟麦 Mic2 /
    扬声器），各接口对应真实设备，需在系统声卡设置（pavucontrol / alsamixer）里
    激活对应接口，即可采集到该接口对应的麦克风/设备声音；
2. **输出设备**：选扬声器/耳机即可；想让其它软件使用降噪后的声音时，
   选 **PureVox 虚拟麦克风**（见下一步）；
3. **采样率**：PipeWire 统一重采样为 48kHz 单声道，无需手动设置。

## 第 2 步：虚拟麦克风（可选）

Linux 虚拟麦克风由 PureVox 经 PipeWire 原生创建，**启动时不会自动创建**：
菜单「**虚拟声卡**」→ 状态面板点「创建」。创建后提供两个出口：

- **PureVox 虚拟麦克风**（purevox_out.monitor）—— 宽口径源，供绝大多数软件选用；
- **PureVox mic**（purevox_mic）—— 供 OBS 等只列"真源"的软件使用（由前者重映射而来）。

其它软件把输入设备设为「**PureVox 虚拟麦克风**」即可收到降噪后的声音；
不用时回菜单「虚拟声卡」点「清理」，创建/清理均安全幂等。

## 第 3 步：开始降噪

点击 **启动音频处理** 按钮，按钮变红即表示降噪已开启。

## 模式说明

五种模式与 Windows 版一致：

- **直通**：不降噪，仅增益 + EQ（含 AGC / VAD / 压缩）；
- **降噪**：AI 实时去噪，日常推荐；
- **AEC**：回声消除 + 降噪，适合用音响的用户，添加「回声消除输入」行并选好麦克风与 far 参考源（扬声器/另一路麦克风二选一）；
- **TSE**：目标说话人提取，先录音录制参考语音，再切 TSE 只保留该人声音；
- **录音**：录制 10 秒参考语音（TSE 的参照样本）。

## 增益 / 均衡器 / VU

与 Windows 版完全一致：前增益（说话时 VU 峰值 **-12 ~ -6 dB** 最佳）、
AGC、VAD，61 段均衡器在菜单「设置 → 均衡器」打开。

## 远程麦克风（手机无线麦克风）

与 Windows 版步骤一致：菜单「音频接口」选「**网络(API)**」→ 启动处理 →
手机浏览器打开电脑显示的网址，或手机装 App 自动发现并推流；降噪后的音频输出到你选定的设备，
想交给其它软件继续选「**PureVox 虚拟麦克风**」即可。

## 数据目录

配置、日志、录音文件均保存在 ~/.purevox/ 。

## 常见问题

**Q：完全没有声音？**

确认 PipeWire 正在运行（ systemctl --user status pipewire ），再确认输入/输出设备下拉是否选对。

**Q：OBS 里选不到虚拟麦克风？**

OBS 只列"真源"：请选 **PureVox mic**，而不是 PureVox 虚拟麦克风（monitor 源）。

**Q：AEC 没有效果？**

AEC 行的 far 参考源要选对：用音响外放选扬声器，对照场景选另一路麦克风。far 参考缺失的行会被跳过并告警。

**Q：怎么卸载虚拟麦克风？**

菜单「虚拟声卡」→「清理」即可，删除安全幂等。
